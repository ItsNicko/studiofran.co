LEGO Sorter: AI Detection & Motor Control

An automated LEGO sorting machine that combines mechanical design, embedded systems, and machine learning into one capstone project. I trained a TensorFlow model to classify LEGO bricks by type and size in real time, designed the full power distribution and motor control circuitry, wired the sensor array, and built an interactive display that shows live classification results and bin assignments. The machine physically routes each brick to its correct bin using servo-driven gates, demonstrating the full pipeline from computer vision to physical actuation.

Codespace-Firefox

An experiment in running the Firefox web browser entirely inside GitHub Codespaces. I configured a headless Firefox instance with X virtual framebuffer, exposed it through a noVNC web interface, and tuned the container so the browser launches and renders web pages inside a cloud development environment. The project explores how far you can push a browser-based desktop experience inside an ephemeral codespace.
